# 研究：換「無面容真人人台」做公仔底（純研究，未實作）

> 2026-11-13（v29c）。用戶提議：保留換制服、換章系統，淨係將下面嘅方塊人換做無面容真人人台（MakeHuman／Mixamo／Ready Player Me）。呢份文件答：做唔做得、點做、要幾耐、有咩風險。

## 1. 先核對用戶講嘅三點

用而家 `src/three/body.js` 嘅尺寸對照一般人體測量約數（成人男約 168 cm；小童約 6–7 歲、117 cm）：

| 部位 | 而家（深資 168 cm） | 真人約數 | 差距 |
|---|---|---|---|
| 頭闊 | 21 cm | 15–16 cm | **闊 ~35%** |
| 頭前後 | 22 cm | 19–20 cm | 大 ~13% |
| 頭高（下巴到頭頂） | 24 cm | 22–23 cm | 差唔多 |
| 膊頭至手臂外闊 | 34 + 2 × 8.5 = 51 cm | 45–48 cm | 闊 ~8% |
| 腳（髖關節高度） | 87 cm（52%） | ~52% | **冇短** |
| 大髀／膝頭／小腿／腳眼 | 一條 14 cm 直柱 | 16–17 → 10 → 11–12 → 7 cm | 冇收窄 |
| 上臂／手踭／前臂／手腕 | 8.5 → 7.5 cm 直柱 | 9–10 → 7 → 8 → 5.5 cm | 冇收窄、冇彎 |
| 小童頭闊 | 18 cm | ~14 cm | 闊 ~29% |

- **第 1 點（比例）**：一半啱。頭闊咗三成係最大問題，所以成個睇落似公仔；但隻腳其實唔短，係因為頭大，加上腳係一條粗直柱，先覺得短。
- **第 2 點（關節）**：完全啱。手腳係直柱，冇膊頭圓位、手踭彎、膝頭，亦冇收窄。v26「流線」只係將方塊磨圓。
- **第 3 點（皮膚）**：大致啱。流線外觀有光暗，但係冇 AO、冇次表面散射，所以似膠。

**點解 Anny 最啱**：
- 一個模型涵蓋 BB 到老人，用年齡、身高、體重、肌肉 slider 控制，並且按 WHO 數據校準。
- 正好對應六個支部（小童軍 117 cm、幼童軍 135、童軍 155、深資／樂行 168、領袖 172／160）。
- MakeHuman base mesh 約 13,000 頂點；預設 rig 有 104 骨。
- 喺呢個沙盒可以直接 `pip install anny` 用（wheel 47.7 MB，要 torch CPU），喺 build 時離線生成 glb，網站唔使跑 Python。
- **注意**：
  - 唔好用佢嘅 `smplx` topology，嗰個只限非商業用途。
  - 有啲 asset 會「需要時下載非商業素材」，要鎖定用 `anny` 或 `makehuman` topology。

## 3. 「啲章黐死喺方塊人上面」？其實唔係

而家嘅架構分四層，換底只係換最底兩層：

| 層 | 檔案 | 換人台要改？ |
|---|---|---|
| 規則 | `src/data/*_rules_v1.0.json` | 唔使 |
| 章位計算（cm，好似紙樣座標） | `badgeLayout.js`（816 行） | 幾乎唔使：佢只讀尺寸（膊頭高、胸袋位、袖長）。由新人台嘅 landmark 計返嗰啲數就得 |
| 身形尺寸 | `body.js` | 改：改由人台 landmark 生成 |
| 3D 畫法 | `Blocky.jsx`、`anatomy.js`、`look.js`、`Badges.jsx` | **重做** |

所以用戶嘅方向架構上啱：規則同排位唔使郁，只係換畫法。

**真正要做嘅唔係「重新黐章」，而係「件衫」。**真人人台係光身嘅：恤衫（胸袋、袋蓋、衣領、肩帶）、短褲、長褲、女裝半截裙、毛衣、小童軍背心、禮服、晚禮服、各款帽、領巾、專章帶、笛繩，全部要按新身形重新做過，而且有六個支部、男女兩款。章貼得準唔準，完全靠件衫做得好唔好。

## 4. 三條路

### 路線 A：唔換底，修正現有程式人形（1–2 輪）
- 頭闊改返 15–16 cm；手腳收窄，加手踭、膝頭彎位；膊頭斜；皮膚加 AO 同柔和光暗。
- 章系統完全唔使郁，零風險；但始終係程式砌出嚟嘅人形，未必達到用戶想要嘅「一睇就知係人」。

### 路線 B：換 Anny 人台，衫由程式生成（建議，約 6–10 輪）
1. **人台**：用 build 時嘅 Python script 生成 12 個身形（6 支部 × 男女），身高同 `body.js` 一樣。
   - 姿勢：手垂低、手踭微彎，烘焙成固定姿勢，唔使 skinning，手機都慳。
   - 面部：用平滑處理變成無面容蛋頭。
   - 每個身形出一份 landmark JSON：頸底、膊頭尖、腋下、胸前、腰、褲浪、膝、腳眼、手腕。
   - 匯出 meshopt 壓縮嘅 glb。
2. **衫**：由身體表面按部位向外推（恤衫比身鬆、袖口放闊、短褲喇開），再切好衫腳、袖口、褲腳。
   - 衣領、袋蓋、肩帶、鈕用 landmark 擺位。
   - **UV 用紙樣 cm**：恤衫前幅攤平之後 1 單位 = 1 cm。咁 `badgeLayout` 嘅 x / y 就可以直接對應件衫。
3. **章**：
   - 布章畫入件衫貼圖（跟住曲面彎，唔會 z-fighting）。
   - 有厚度或者金屬嘅章用 three.js `DecalGeometry`。
   - 勳章、笛繩、專章帶、領巾就沿表面取樣做 mesh。
4. **專章帶、笛繩、領巾路線**：改用 landmark 計。
5. **帽**：按頭圍重新做。頭髮可以唔要，人台通常冇頭髮；如果要，就做簡單髮型。
6. **測試**：
   - `badgeLayout` 現有測試照用。
   - 新增測試：landmark 一致性、紙樣到表面誤差 < 0.3 cm、章唔穿衫、size budget。
- **大細**：12 個身形每個約 150–300 KB（meshopt），加衫，總共約 +2–4 MB，喺 10 MB 上限之內。可以按支部 lazy-load。
- **風險**：
  - 向外推出嚟嘅衫容易似緊身衣，要逐區調鬆緊。
  - 禮服、晚禮服同半截裙最難做。
  - 專章帶同領巾喺曲面上嘅路線要重新計。

### 路線 C：Blender 手做衫（MPFB2 衫會自動貼合各身形，約 8–12 輪或者要美術幫手）
- 衫只要做一次，就會自動貼合 12 個身形，質素最好。
- 但要 Blender 人手造型。`bpy` wheel 要 Python 3.13，沙盒係 3.11；就算裝到，我都冇得互動咁雕。除非有 3D 美術幫手，否則唔建議。

## 5. 建議

1. **先做一輪 spike**：
   - 用 Anny 生成領袖男 172 cm 無面人台。
   - 只做恤衫上身，向外推，有胸袋同袋蓋。
   - 貼六個基本章同特區章（用紙樣 cm 對位）。
   - 同現時方塊人並排截圖，等用戶判斷係咪真係「一睇就知係人」，先決定做唔做全套。
2. Spike 通過就行路線 B：
   - 次序：上身恤衫 → 褲／裙 → 袖章 → 帽 → 領巾／專章帶／笛繩 → 禮服。
   - 每輪一個 PR。
   - 舊外觀保留做「簡約」選項，直到新底覆蓋晒所有制服。
3. Spike 唔滿意，就退返路線 A，修正比例同關節。
