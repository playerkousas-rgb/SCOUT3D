### 要你決定嘅問題

1. **進步獎章「左下／右下」係邊個角度？** 指引冇寫。模型而家當「望住佢左袖嘅人」嘅角度：紅（第 1 步）、藍（第 3 步）靠穿著者**前面**，啡、綠靠後面。如果應該倒轉，改 `src/three/Figure.jsx` 入面 `cells` 嘅 z 正負號，再改 JSON `pendingReason`。
2. **「縫線上方」留幾多？** 文件冇寫距離，模型留 0.5 cm。
3. **小草蜢獎章位置同尺寸**：第三版指引附圖文字版讀唔到；請對照紙本 P.12 附圖。
4. **旅章、區章、優異旅團章、紀念章嘅尺寸**：文件冇寫，模型用估計尺寸（資料標 `measured: false`，UI 寫「文件未列明，模型示意」）。

## D. 唔可以

- 除上列徽章外唔可以戴其他徽章（UH p.24；GSG P.9）。
- 除顏色巾圈外，唔可以用其他支部制服配件，例如皮帶、制服帽（UH p.24；GSG P.9）。
- 世界童軍會員章等基本徽章適用於「青少年成員（小童軍除外）」（UH p.26）。
- 布質名牌適用於童軍成員（小童軍除外）（UH p.128）。
- 小童軍服務年星升幼童軍後先戴，唔可以戴喺小童軍服裝（UH p.129）。
- 未宣誓：可穿全套服裝（唔使扣領釦），團員章同旅巾宣誓後先戴（UH p.24）。

## 核對完點改

1. 每項剔完，喺 JSON 將該項 `status` 改做 `"verified"`（或者改位置後保留 `"pending"`）。
2. 填 `review.lastChecked`（例如 `"2026-11-20"`），`review.status` 改做 `"verified"`。
3. `npm run check` → `npm test`（`tests/rules.test.mjs` 有一條「v1.0 唔可以有 verified」，核對後要一齊改）→ 改版號 v1.1（V 規則：檔名、內文、頁尾、CHANGELOG）。
