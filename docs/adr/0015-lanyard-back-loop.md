# 0015 — 嘉許笛繩後面一段（套住左膊嘅圈）

SCOUT3D v1.0 · © SCOUT SYSTEM

- Status: accepted（2026-11-15）

用戶睇完 v19 截圖（正面、背面）覆：「你畫左前面無畫後面」。v19 只畫咗由職級肩章下面向前落去嗰段，背面淨係見到肩章後面凸出一小截繩頭。

## 決定

笛繩係一個圈套住左膊（相片 image-11 見到前面一段由肩章下面落到腋下）。加後面一段 `lanyardBackPoints()`（`src/three/body.js`）：

| 點 | 位置 |
|---|---|
| 1 | 職級肩章下面（同前面一段第一點一樣） |
| 2 | 肩帶後邊穿出（仍然喺肩章下面，繩面唔高過肩章） |
| 3 | 袖頂後邊 |
| 4 | 兜落袖後面 |
| 5 | 沿袖窿後面（貼住背，身邊 torso.w/2 − 0.8） |
| 6 | 腋下（身同手臂之間、z = 0，喺短袖入面，望唔到） |
| 7 | 同前面一段喺袖窿前面（top − 9）嗰點接埋 |

- 晚禮服小型笛繩：接埋之後再去左襟領（同前面一段第三點）。
- `Lanyard` 改收 `paths = [前面一段, 後面一段]`，兩段用同一套四元數分段（`lanyardSegments`），撳邊段都揀到同一個章。
- 顏色、粗幼、前面一段路線冇改（v19 已確認）。

## 後果

- 測試加 `tests/v20.test.mjs`（5 個）：後面一段同前面一段同點起、喺肩章下面、肩帶後邊穿出、袖頂後邊唔插入袖、貼住背面、腋下喺身同手臂之間、最尾同前面一段接埋；晚禮服接去左襟領；Blocky 畫兩段。
- 背面截圖見到繩由肩章下面沿袖窿後面落去腋下。

## 補充：高級嘉許笛繩顏色（用戶：「顏色不對，高級是紫色的」）

v15 起高級嘉許畫成「深藍夾黃綠」，係錯讀咗 P.184 相片。放大相片：紫色主繩纏住一條幼米白線。

- `LANYARD_COLOURS`（搬去 `body.js`，可以測）：嘉許 = 橙金色一條；高級嘉許 = 紫色主繩（`#5b2d72`）＋幼米白扭紋（粗幼 0.35）。
- 每條 strand 有自己粗幼（`w`），`strandOffsets()` 計並排位置；`Lanyard` 按 `w` 畫。
- 測試：高級嘉許主色係紫色、扭紋幼過主繩、`strandOffsets` 數值。
