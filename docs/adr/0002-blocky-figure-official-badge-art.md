# 0002 — 方塊人公仔 + 徽章用官方文件圖案

2026-11-14 用戶睇完寫實 MakeHuman 公仔（膊頭變三角形）之後，決定改做「Minecraft 方塊人，不過係真實比例」（約 6 歲、117 cm），所以人物全部係長方體（`src/three/body.js`、`Blocky.jsx`），唔使下載模型。用戶同日指示「章記得用制服手冊的，別自己設計」，所以徽章圖案改為直接取自香港童軍總會官方文件：團員章取自《儀容與制服手冊》P.23；進步獎章、小草蜢獎章取自《小童軍活動指引》（第三版）P.11–12；旅章、區章、優異旅團章、紀念章用手冊 P.25 附圖嘅示例（各旅／區實際圖案唔同，UI 標「手冊示例圖案」）。圖案檔放 `public/badges/`，每個章喺規則 JSON 寫 `art`（檔名 + 文件 + 頁碼），`validate.js` 冇來源就攔。徽章位置由 `src/three/badgeLayout.js` 用 JSON 嘅 `size` / `anchor` 計，`tests/badge_layout.test.mjs` 鎖死手冊距離同「唔疊、唔出袖」。

- **Status**: accepted（取代 ADR-0001 嘅「程序生成卡通公仔」同「canvas 簡化示意徽章」部分）
- **Considered Options**: (1) 繼續寫實 MakeHuman 公仔：用戶兩次否決；(2) 自己畫簡化徽章：用戶明確話唔好自己設計。
- **Consequences**: 徽章圖案版權屬香港童軍總會，頁面同來源分頁都寫明出處；repo 係私人、非商業。袖用闊身（外側面 10.5 cm、袖長 15.5 cm）先擺得落手冊 P.94 嘅旅章（最少 8.5 cm 闊）同 P.95 嘅區章（3.8 × 5 cm）。
