# 0028 — 人形定案：刪走試做 A，保留「現有」，深化 B 人台

SCOUT3D v1.0 · © SCOUT SYSTEM

- Status: accepted（v31）
- 取代 ADR-0027 嘅「試做 A／B」部分（「只留流線」照舊）

用戶 v31：「B 係好好多，可以刪走 A 保留現有 再深入改進 B」。

## 決定

1. **刪走試做 A**：`FIGURES = ['current', 'b']`；`figureLayout`／`HEAD_A`／`torsoA`／`ELBOW_BEND_A`、A 嘅 i18n 字、相關測試全部刪；`anatomy.js` 還原 v29c 版本（只加 `headRadiusAt` 嘅 `radiusAt` hook，俾 B 帽貼真頭型）。預設人形仍然係「現有」。
2. **B 唔另外畫配件**：所有配件（旅巾、衣領、肩帶、肩章、領巾尖章、木章、領呔、晚禮服襟領章、笛繩、專章帶）照用方塊公仔嗰套厘米位置砌，再用 `bodyWarp` 由「方塊世界」變形去人台身上。規則、badgeLayout、配件尺寸只有一份，兩款人形一定一致。

## 方塊 → 人台變形（`src/three/mannequin.js` `bodyWarp`）

- 上身：每點量離方塊前／後／左／右／膊頂幾遠（t），擺返去人台衫面外面同樣 t；近角位 softmax 加權。前／後面嘅 x 用 `squeeze` 收入人台嗰度「前面」嘅闊度（`faceRange`：由中線行到表面退後 > 0.35 d 為止，女仔胸口向前，唔會俾側面吸走）；高過領口嘅點用領口嗰點（`faceTop`，唔會見到後面衣領）。
- 頸（`neckWarp`，`userData.warp = 'neck'`）：方塊頸外面 t、角度 θ → 人台頸（`neckField` 極座標高度圖）外面 t，跟頸底前低後高；旅巾圈、衣領用。
- 前面平放（`frontWarp`，`userData.warp = 'front'`）：旅巾前面兩條只用正面投影 —— 以前膊頂候選會將旅巾頂拉過膊頭，幼童軍見到兩條深色尖角。
- 笛繩（`route`）：轉角點先變形（變唔到嘅用前後點位移插值，`warpPolyline`）→ 切細 1.2 cm → 每點推出衫面（`pushOut`：前、後、左、右、膊頂五個高度圖都喺表面下面先推，揀「深度 ÷ 半闊」最細嘅方向）；腋下嗰兩段（手臂下面兜過去）唔推，收埋喺手臂下面。以前笛繩一截截浮喺左膊外面／陷入衫入面。
- 外衣（`garmentRules(..., outer)`）：毛衣、背心、禮服外套 = 恤衫外面再一層殼，用外衣貼圖（袋、鈕、襟領）；衫腳最低去到褲襠上面 2 cm（再低就變咗兩條褲管，禮服褲襠露窿）。
- 鞋（`inflateSmooth`）：只可以向外嘅平滑，腳趾罅填平（唔再似黑色光腳）。
- 頭髮（`hairRules`）：頭皮外面一層殼，髮腳同現有公仔一樣（`hairDrop`）；切細 0.5 cm 加一撮撮坑紋同深淺。戴帽時：人台帽係跟眉擺（帽口離眉 2 cm），所以眉上 3 cm 以上嘅頭髮收埋，帽口下面由薄漸厚，唔會穿出帽、唔會露頭皮。孖辮未做（女仔係及下巴短髮）。
- 帽：用人台個頭嘅 `headBox` ＋ 真實半徑（`radiusAt`）同眉高，軟帽、帽帶貼頭皮。

## 驗證

- 本機 headless 截圖（leader 笛繩前後、禮服外套、毛衣、幼童軍旅巾、童軍背後三角、小童軍鞋、女仔頭髮）。
- `tests/v31.test.mjs`（6 個）：heightField 範圍、`warpPolyline` 插值、四款身形笛繩連續（每步 < 3.5 cm）兼喺心口前面唔陷入衫、旅巾前面唔會俾拉到身後、外衣衫腳唔低過褲襠、鞋平滑整體向外。測試共 318 個。

## 未做／已知

- 孖辮、幼童軍衣領白點、女仔袋蓋綠色印、眼角雜點；旅巾圈喺膊頭兩端略皺；背後三角邊位少少鋸齒。
