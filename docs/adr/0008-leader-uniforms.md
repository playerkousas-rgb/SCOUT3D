# 0008 — 成年成員（領袖）制服編號 3–6

- Status: accepted（2026-11-14）

用戶指示：「領袖有很多不同款要小心點」。範圍（用戶揀）：先做制服編號 3–6；四個單位層級（旅／區／地域／總部），職級跟層級篩選；領巾全套（旅巾、會巾、基維爾領巾），基維爾巾圈同木章分開揀；成年方塊人男 172 cm、女 160 cm，冇身形滑桿。

- 右袖（P.94–95）：旅 = 旅章，下面地域章 + 區章並排；區 = 香港肩章，下面地域章 + 區章；地域 = 香港肩章 + 地域章（只得一個，放中間）；總部 = 香港肩章 + 總會總部章（放中間）。
- 職級帽章同職級肩章（P.103–104 表格，16 款肩章、9 種帽章顏色）；肩章套喺肩帶膊頭嗰頭，徽號向衣領（P.106、P.172）；「R」字樣別針喺肩章徽號下面（P.105）。
- 硬帽（P.100）：女性著編號 3、4；海／空童軍領袖、著長褲、教練員唔戴；帽章喺右耳嗰邊。
- 領巾（P.108–111）：旅巾 = 旅成員；會巾（深綠色，領巾尖香港章）= 區或以上幹部、會務委員、專業領袖、受薪職員；基維爾領巾 = 木章持有人。木章訓練第 4 階段 → 基維爾巾圈；第 6 階段 → 木章（P.115–117），助理領袖訓練主任 3 顆、領袖訓練主任 4 顆木珠；訓練隊嘅基維爾巾圈有「斧頭木」標誌。

## 決定

- **新規則 `leader_rules_v1.0.json`**：頂層多咗 `levels`、`ranks`（34 個職級，每個有 `levels`）、`uniforms`（u3–u6，`genders`、`neckwear`、`legwear`）。徽章加 `levels`（邊個層級戴）；職級肩章 `dynamic: 'rank'` + `rows`（每行 = 一款肩章 + 一款帽章 + 職級清單，全部寫來源頁碼）。`validate.js` 檢查每個職級都有一行、圖檔路徑、層級 id。
- **圖案全部由手冊裁出**（`public/badges/leader/`，30 個 PNG 共約 256 KB）：16 款肩章、9 款帽章、香港肩章、總會總部章、海童軍領袖帽章、基維爾格仔布、「R」別針。
- **擺位**：`placeAll()` 新增肩帶上嘅「向衣領」擺法（`upTowards: 'collar'`）同「喺另一個章上面」（`onBadge` + `alongCm`）；`visible(…, { level })` 跟層級篩；淨低一個地域章／總會總部章時沿用 `centreLonePair()` 放中間。
- **身形**：`LEADER_BODY` 由深資童軍 168 cm 按比例放大（男 172）／縮細（女 160），肩帶闊度、袖口邊唔跟比例。
- **服裝分頁**：款式、人物、制服編號（男 3／4／5、女 3／4／6；轉人物時 5 ↔ 6）、帽（女：硬帽／軟帽；陸上可揀深資童軍領袖棗紅色軟帽）、木章訓練進度、領巾（唔合資格嘅選項停用）、巾圈、木章。
- 成年成員一律當已宣誓。

## Considered Options

- 每個職級一個開關：太多（34 個）；改做層級 → 職級選單，肩章、帽章自動跟。
- 硬帽、白頂帽、木章用方塊示意（唔係真實造型），徽章圖案用手冊原圖。

## Consequences

- 頂部切換有六個支部（手機分兩行）。
- 編號 1 禮服、編號 2 晚禮服同勳章已喺 [ADR-0009](0009-leader-dress-uniforms.md) 做咗。
