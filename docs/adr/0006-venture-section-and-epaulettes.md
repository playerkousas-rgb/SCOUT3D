# 0006 — 深資童軍支部＋深資童軍肩章選項

SCOUT3D v1.0 · © SCOUT SYSTEM

- Status: accepted（2026-11-14）

用戶指示：「繼續進行深資童軍支部 肩章也算是必備章類要加選項」。

## 背景

手冊 P.36–41 同綱要 P.14–15：深資童軍、深資海童軍、深資空童軍嘅徽章欄一樣（世界童軍會員章、香港章、地域章、區章、旅章），冇小隊章。手冊 P.170 附圖寫明「包括深資海童軍及深資空童軍」。

| | 深資童軍 | 深資海童軍 | 深資空童軍 |
|---|---|---|---|
| 帽 | 棗紅色軟帽 + 童軍帽章 | 海童軍男／女領袖白頂帽 + 深資海童軍帽章 | 灰藍色軟帽 + 童軍帽章 |
| 恤衫 | 杏色、肩帶 | 白色、肩帶 | 淺藍色、肩帶 |
| 男 | 草青色長褲、黑短襪、綁帶皮鞋 | 深藍色長褲 | 深藍色長褲 |
| 女 | 草青色半截裙（及膝）、肉色襪褲、非綁帶中跟皮鞋 | 深藍色半截裙 | 深藍色半截裙 |

深資童軍肩章（手冊 P.145；綱要 P.19）係訓練獎章：為剛獲頒會員章嘅深資童軍而設，完成後由深資童軍團長簽發，戴喺恤衫或制服毛衣雙肩肩帶上。

## 決定

- **新支部 `venture_rules_v1.0.json`**，同童軍一樣用 `variants`（land／sea／air），每款只換帽、恤衫、長褲／半截裙。
- **肩章當必備章，但有選項**（用戶指示）：徽章加 `choices`（`none` 未考獲／`venture` 深資童軍肩章）同 `default`。驗證要求：最少兩個選項、要有一個冇章選項、有圖案就要有官方來源頁、`default` 要係其中一個。徽章分頁用分段掣揀，唔係開關。
- **擺位**：`anchor.part = 'shoulder'`、`side = 'both'`。`strapLayout()` 計肩帶（由膊頭邊到衣領）；肩章平放喺肩帶上，方頭（徽號）近膊頭、圓頭近衣領（P.145、P.170 附圖）；右膊圖案右手邊向衣領，左膊同一款章轉 180°。有 three.js 測試鎖定方向。
- **尺寸**：手冊冇寫，用 9 × 3.8 cm（P.145 圖案比例），要擺得落肩帶。
- **圖案**：肩章取自手冊 P.145、深資海童軍帽章取自 P.102，都係細圖裁出嚟放大，冇重畫（共約 20 KB）。
- **身形**：約 18 歲、168 cm。女團員可以揀半截裙／長褲（綱要 P.15），預設半截裙（手冊）。
- **待確認（寫入 `conflicts`）**：綱要有「領呔」一行但手冊冇（模型畫旅巾）；深資空童軍帽章手冊寫「童軍帽章」、綱要寫「成員帽章」（跟手冊）；女團員長褲只見於綱要。
- 手冊 P.170 附圖喺旅章同地域／區章中間有深資童軍急救章；呢版只做必備章，所以地域／區章照 P.95 文字喺旅章下 2 cm。

## Considered Options

- 肩章做普通開關：用戶要求「加選項」，而且之後可能要加其他款（例如制服毛衣），所以用 `choices`。
- 樂行童軍肩章放入選項：屬樂行童軍支部，唔放。

## Consequences

- `placeAll()` 多咗 `facing: 'up'` 同 `rot`；`visible()` 按 `state[id] === choice` 顯示。
- 聚焦平放嘅章時相機由前面斜上望，唔會由頭頂直落。
- 之後樂行童軍可以用同一套 `choices`（樂行童軍肩章）。
