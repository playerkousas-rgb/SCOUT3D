# 0025 — 流線細節（立體頭髮、手指、耳仔、鼻）＋手機版面

SCOUT3D v1.0 · © SCOUT SYSTEM

- Status: accepted（2026-11-15）

用戶 v27：「我最想要的圓是什麼 是能看到手指，髮型那種」；另外「在手機上看完全看不到右側面版」。

## 決定 — 流線細節（只限「流線」外觀）

- 新模組 `src/three/anatomy.js`（形狀計算）同 `src/three/Anatomy.jsx`（`SmoothHand`、`SmoothHead`）。頭、手冇章，`badgeLayout.js` 同規則 JSON 冇郁。
- **頭髮**：`hairGeometry` 沿 theta（圍住頭）× phi（由頭頂落）嘅格，每條直線由頭頂去到髮腳（`hairDrop`）；表面 = 頭表面（`headSdf`／`headRadius`，同 `smoothBox` 一樣嘅圓角形狀）+ 厚度（頂厚邊薄）+ 一撮撮梳紋；最後一行摺返入頭皮，邊位有厚度。男仔：短陰一撮撮、鬢角、耳仔露出、後面去到 15 cm；女仔：齊陰、兩邊遮耳、後面去到下巴，孖辮改做上幼中脹尾尖有梳紋（`pigtailGeometry`）加紫色髮圈。戴帽時頭髮壓薄（帽唔會俾頭髮穿出）。流線嘅頭貼圖唔再畫頭髮（`headFaces(B, smooth)`，只畫五官）。
- **手**：手掌（圓滑）＋四隻手指（兩節膠囊，微微向掌心屈，食指喺前）＋拇指（向前向內）；左右鏡像。
- **耳仔、鼻**：立體（位置同原本畫上去嘅一樣）；女仔長髮遮住耳仔唔畫。下巴收圓多啲（`reBot` 0.26 × 高）。

## 決定 — 手機

- 原因：手機版 3D 區設咗 `touch-action: none`，佔大半個畫面，手指喺公仔上面掃唔到落去設定面板；打橫時更加冇位。
- 3D 區改 `touch-action: pan-y`：上下掃 = 捲頁，左右拖 = 轉身，雙指 = 縮放；3D 區高度 50svh。觸控裝置顯示觸控提示（`hint.touch`）。
- 手機／細平板打橫（闊 600–1023 px、高 ≤ 560 px）：公仔喺左、設定面板喺右（同電腦一樣），各自捲；檢視掣一行、可以左右捲。
