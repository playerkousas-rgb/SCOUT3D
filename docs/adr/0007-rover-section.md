# 0007 — 樂行童軍支部

- Status: accepted（2026-11-14）

用戶指示：「我檢查深資童軍支部，你繼續進行樂行童軍支部」。

## 背景

手冊 P.42–47 同《樂行童軍支部訓練綱要》（2026-05-19 版）P.10–11：樂行童軍、樂行海童軍、樂行空童軍嘅徽章欄一樣（世界童軍會員章、香港章、地域章、區章、旅章），冇小隊章。手冊 P.171 附圖寫明「包括樂行海童軍及樂行空童軍」，擺位同深資童軍（P.170）一樣。

| | 樂行童軍 | 樂行海童軍 | 樂行空童軍 |
|---|---|---|---|
| 帽 | 深綠色軟帽 + 童軍帽章 | 海童軍男／女領袖白頂帽 + 樂行海童軍帽章 | 灰藍色軟帽 + 童軍帽章 |
| 恤衫 | 杏色、肩帶 | 白色、肩帶 | 淺藍色、肩帶 |
| 男 | 草青色長褲、黑短襪、綁帶皮鞋 | 深藍色長褲 | 深藍色長褲 |
| 女 | 草青色半截裙（及膝）、肉色襪褲、非綁帶中跟皮鞋；或長褲 + 黑襪 + 綁帶（P.51） | 深藍色 | 深藍色 |
| 領帶（P.49、P.113） | 深綠色 | 黑色 | 深藍色 |

- 帽章：手冊 P.102「深資／樂行海童軍帽章」係同一個，所以樂行海童軍用返 `venture_sea_cap_badge.png`。
- 樂行童軍肩章（手冊 P.145；綱要 P.12–13、P.18）：深綠色、「ROVERS」字 + 童軍徽。係進度性訓練第二階段（會員章之後）：完成樂行童軍啟導班或同等項目，經團長推薦，由區長／助理區總監（樂行童軍）等確認簽發；完成先修章嘅成員晉團後當已完成。

## 決定

- **新規則 `rover_rules_v1.0.json`**，由深資童軍規則複製後逐項改：頁碼（P.42–47、P.49、P.51、P.171）、綱要改用 `RTS`（P.10–11、P.18）、深綠色軟帽／領帶／肩章。檢查同測試會攔「P.170」、「棗紅」、`VTS`。
- **肩章當必備章，有選項**（用戶喺深資童軍定落嘅規矩）：`none` 未考獲／`rover` 樂行童軍肩章，預設已考獲。圖案由手冊 P.145 原圖裁出（`public/badges/rover_epaulette.png`，約 8 KB，同深資童軍肩章同尺寸 414 × 174）。
- **身形**：樂行童軍 18–26 歲；沿用深資童軍 168 cm 方塊人（`ROVER_BODY = VENTURE_BODY`）。擺位全部以 cm 計，測試鎖定同深資童軍一樣（除咗肩章圖案）。
- **程式**：`isSenior(section)`（深資／樂行）代替 `section === 'venture'`，Blocky 用 `roverVariant()`；App 用 `SENIOR` 同 `SENIOR_KEY` 揀說明字句。冇另開新組件。
- **同深資童軍一樣嘅選項**：款式、半截裙／長褲、旅巾／領帶、制服毛衣（肩章戴喺毛衣肩帶上，P.122）。

## 用戶核對（`review.userChecks`）

2026-11-14 用戶回覆「你要核對的都全對」：下面四項由 `conflicts` 移入 `review.userChecks`。

### 原本待確認

1. **帽章**：手冊 P.42、P.46、P.102 寫「童軍帽章」，綱要 P.10–11 寫「成員帽章」。模型跟手冊（同深資空童軍嘅用戶決定一樣）。
2. **樂行海／空童軍毛衣顏色**：手冊 P.121 寫「海童軍／空童軍青少年成員」深藍色；模型當包括樂行海／空童軍（深資海／空童軍用戶已確認）。
3. **領帶宣誓前可唔可以戴**：手冊冇講；模型跟深資童軍（用戶確認）宣誓後先戴。
4. **身形**：沿用 168 cm。

## Considered Options

- 樂行童軍另開身形（例如 172 cm）：要重新校袖長、肩帶同相機，冇手冊數據支持；擺位同 P.170／P.171 一樣，所以沿用。
- 綱要嘅「成員帽章」：同手冊唔同，跟手冊（主要參考係制服手冊，用戶指示）。

## Consequences

- 頂部切換有五個支部；`check_rules` 檢查樂行童軍規則同肩章圖檔。
- 之後加樂行童軍急救章、社區參與章、樂行童軍獎章、貝登堡獎章、寰宇童軍章時，位置跟手冊 P.171 附圖。

## 更新（2026-11-14，用戶第二輪）

用戶確認上面四項全對，另外指正：

- **半截裙似短褲**：裙中間有條線。新 `skirtFaces()`（只畫裙腳摺邊）；`cubTorsoFaces({ skirt })` 唔畫皮帶下面嘅褲頭中線。深資童軍一齊改。
- **肩帶同肩章要去到膊頭**：`strapLayout().outer` 改做 `shoulderTip(L)` = 袖頂外邊（`armX + sleeve.w / 2 − 0.3`），肩章方頭貼住膊頭。著毛衣時肩帶盒向下加厚到膊頭（`boxT`、`boxY`），袖頂上面冇隙。幼童軍、童軍恤衫嘅肩帶貼圖都延伸到袖頂（`sleeveFaces` 頂面），身上嗰截膊頭嗰頭唔再畫邊。
- **地域章／區章只得一個就放中間**：例如總會總部屬下嘅銀禧區冇地域章，或者熄咗其中一個。`visible()` 之後行 `centreLonePair()`，淨低嗰個章 `u = 0`，高度唔變；原本位置資料唔改。幼童軍、童軍、深資、樂行都適用；之後總會幹部制服只得一個總會章都照用。
- **女裝非綁帶中跟皮鞋**：唔再用轉色表達中跟。`pumpParts()` 用方塊砌：後面中跟、斜落嘅腳弓、前面鞋掌貼地，腳弓下面留空（側面見到個窿）；鞋面開口大，腳面同腳趾見到肉色襪褲，黑色只係鞋邊同鞋頭。`shoeFaces` 刪咗 `pump` 選項。
