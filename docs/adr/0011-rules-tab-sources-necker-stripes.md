# 0011 — 「規定」分頁、服裝／徽章分頁拎走小備註、來源只列文件、旅巾斜紋加闊、旅巾背後長度、領袖獎勵

SCOUT3D v1.0 · © SCOUT SYSTEM

- Status: accepted（2026-11-13）

用戶睇完 v13 之後提出四項修改（第 1–4 點）；之後再提出旅巾背後太長，同埋講清楚「領袖配件」係指邊啲獎勵（第 5–6 點，2026-11-15）。

## 決定

### 1. 旅巾斜紋加闊一倍（條數減一半）

- `src/lib/necker.js` `STRIPE_W`：1.6 cm → **3.2 cm**。用戶話 1.6 cm 太密，睇落眼花，要每邊減一半。
- 只改巾尾、捲邊嘅斜紋（`paintStripes`）；背後三角嘅平行色邊（每條 1.2 cm）唔變。

### 2. 服裝、徽章分頁拎走小備註（全部支部）

- 小草蜢、幼童軍、童軍、深資、樂行、領袖嘅服裝分頁同徽章分頁，唔再顯示灰色細字備註同黃色提示框。`Switch` 唔再收 `note`。
- 保留：
  - 撳徽章後嘅資料卡。佢本身就係內容，會解釋點解個章而家唔顯示。
  - 優異旅團章年份錯誤提示。佢係輸入檢查，唔係備註。
- 純粹講模型嘅句子刪咗，包括「模型只畫短褲」、「方塊造型只係示意」同「顏色可以自己揀」。關於斜紋畫法同左右分色嘅說明（`neckerStripeNote`、`neckerSplitNote`）、`socksHidden`、`leaderFigure` 都刪走。

### 3. 新增「規定」分頁（`tab.rules`）

- 分頁次序：服裝、徽章、**規定**、來源。
- 內容由 `src/rulesGuide.js` 定義。每個支部按主題分組，每組係一列重點：
  - 制服、宣誓前後、學校運動上衣、帽、領巾／巾圈／領帶、制服毛衣、徽章；
  - 領袖另外有單位層級、制服編號、木章、勳章及獎勵。
- 項目重用原有 i18n key，即係以前顯示喺分頁度嗰啲備註。字眼改成規定嘅寫法：
  - 「而家揀咗長褲」→「女團員揀長褲時」；
  - 木章由「而家職級 {n} 顆」改成「一般 2 顆，助理領袖訓練主任 3 顆、領袖訓練主任 4 顆」；
  - 刪走「用戶確認」字樣。
- 有陸上／海／空款式嘅支部，分頁頂有「顯示款式」選擇，預設跟住服裝分頁嘅款式；只列嗰個款式嘅項目（`guideFor(section, variant)`）。
- 領袖嘅單位層級同制服編號說明，由 `leader_rules_v1.0.json` 嘅 `levels`／`uniforms` 讀出（`{ json: 'levels' }`）。
- 以前喺「來源」分頁嘅「逐件規定」、「未宣誓」、「唔可以戴」、「文件之間嘅分別」搬嚟「規定」分頁尾。

### 4. 「來源」分頁只列文件

- 只列以下文件，每份顯示版本日期同「開啟」：
  - 《儀容與制服手冊》（UH）；
  - 《小童軍活動指引》（GSG）；
  - 幼童軍、童軍、深資童軍、樂行童軍支部訓練綱要（CTS／STS／VTS／RTS）。
- 唔再列網頁（WEB）、PAI、GLH；規則 JSON 嘅 `sources` 冇改。徽章資料卡同「規定」分頁嘅逐項出處照舊顯示頁碼。
- 保留一行手冊版權聲明。徽章圖案版權已經喺頁腳免責聲明（「取自香港童軍總會官方文件及網頁」）。

### 5. 旅巾背後三角縮短到背後擔干橫線

- 用戶附圖：背後三角太長，尖去到背後橫線（膊頭擔干）就夠。
- `body.js` 新增 `SHIRT_YOKE = 9`（擔干離膊頂 9 cm），恤衫貼圖同旅巾共用呢個數。
- 有胸袋嘅杏色恤衫（幼童軍、童軍、深資、樂行、領袖編號 3／5／6）：`back.h = SHIRT_YOKE`。
- 小童軍活動服冇擔干，長度唔變。學校運動上衣模式嘅團員章位置跟小童軍，唔受影響。

### 6. 領袖獎勵（香港總監嘉許／高級嘉許、獅／龍勳章、銅狼）

- 用戶指示：勳章及獎勵（15 組，包括嘉許笛繩、掛頸勳章、勳章排、感謝章）**編號 1–6 全部制服都可以戴**，唔再只係禮服、晚禮服。
  - 編號 3–6 用恤衫嘅位置：勳章排喺右胸袋袋蓋上方，笛繩由左肩肩帶落左胸袋，感謝章喺右胸袋袋蓋。
  - 掛頸勳章喺編號 3、5、6 嘅領巾、巾圈同木章前面（z = 胸口 + 2.4 cm），喺編號 4 嘅領帶前面。
- **銅狼獎章**（Bronze Wolf）：
  - 加入掛頸勳章做最高級（`order: 1`），排喺選項最尾。
  - 同獅、龍係同一個單選，所以有銅狼就只戴銅狼（用戶指示）。
- 銅狼圖案：
  - 手冊冇銅狼圖案，用戶都冇相（可能要 WOSM 先有）。
  - 暫時用示意圖：綠底黃邊 V 字綬帶加銅色狼像，150 × 200 px，同其他勳章相同格式（`public/badges/awards/bronzeWolf.png`）。
  - `art.drawn: true`，資料卡顯示「示意圖（手冊冇圖案，自行繪畫）」。
  - 來源 `WOSM` 寫明係示意。將來有官方相就直接換檔，再拎走 `drawn`。
- 測試 `leader.test.mjs`：編號 3 而家會顯示感謝章。
