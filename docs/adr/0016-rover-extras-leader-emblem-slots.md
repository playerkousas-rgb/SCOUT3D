## 決定

### 1. 佩戴「行」（`rules.slots`）

以前每個章有自己固定位置。非基本章好多係「同一行並排、冇嘅就補位」，所以加一種錨點：

```json
"slots": { "pocketR": { "part": "torso", "side": "right", "layers": [{ "id": "flap", "gapCm": 0, "max": 3, "from": "outer" }, …], "clearRacks": true, "zh": "…", "en": "…", "sources": […] } }
"anchor": { "part": "torso", "side": "right", "slot": "pocketR", "layer": "flap", "rank": 1 }
```

- 每層按 `rank` 排，`max` 之後嘅章唔顯示（原因 `slotFull`，提示熄咗前面嘅章先會顯示）。
- 每層並排，相隔 0.4 cm，置中；太闊就一齊縮細。`from`：`inner`／`outer`（胸袋）、`front`／`back`（袖）表示第一個章喺邊邊。
- 胸袋：由袋蓋頂向上疊；`gapIfAboveCm` 係上面仲有一層時用嘅距離（例：飛行章單獨 3 cm，上面有香港章時 2 cm）；`clearRacks` 令成行喺勳章／勳條上面。
- 袖：由 `fromShoulderCm` 或 `belowBadge` 向下疊；上面嘅層冇章就由下一層補上去。
- 選項（choice）可以改 `layer`／`rank`（例：成年成員揀跳傘章就同寰宇童軍章並排）。
- `hiddenBy` 而家接受任何章：樂行童軍會員章 `hiddenBy: ["peace"]`（原因 `replaced_peace`）。
- `validate.js` 檢查 slot 有冇登記、part／side 對唔對、layer 存唔存在、`rank` 係整數、圖有 `px`。
