用戶 v22：

2. 深資童軍跟 2026 年新版《深資童軍支部訓練綱要》（第 11 版）放章，同樂行童軍一樣以綱要為準。

## 決定

### 1. 模範童軍肩帶（手冊 P.158）

> 「掛在制服恤衫右肩肩帶之下，肩帶末端扣在右胸袋袋蓋左方位置。」成年成員可繼續佩戴；同時獲頒香港總監嘉許／高級嘉許就只揀一條；唔戴喺西服、制服毛衣、禮服、晚禮服。

- 新章 `modelScout`：童軍、深資童軍、樂行童軍（`group: 'extra'`）同成年成員（`group: 'awards'`，只限編號 3–6，`hiddenBy: ['commendation']`，原因 `replaced_commendation`）。幼童軍唔加：模範童軍選舉對象係童軍或以上。
- 錨點沿用笛繩：`{ part: 'torso', side: 'right', lanyard: true, lanyardEnd: 'flapInner' }`。
- `lanyardPoints`／`lanyardBackPoints` 加 `side`（−1 = 右肩，將左肩路線左右反轉）同 `end`（`pocketMouth` = 嘉許笛繩入左胸袋口；`flapInner` = 扣喺胸袋袋蓋近中線嗰邊）。成個圈套住右膊，前面一段落到胸袋下面再兜返上袋蓋。
- 顏色 `LANYARD_COLOURS.modelScout`：深綠 `#2e5e3a`／金黃 `#d4b23a` 扭紋（每 0.9 cm 轉色）＋末端穗，跟 P.158 相片。
- 童軍模型冇畫肩帶：`strapLayout(L, { virtual: true })` 計一條唔畫、冇厚度嘅肩帶俾繩行。
- 毛衣唔戴（`sweater: false`；領袖毛衣名單冇佢）。

### 2. 深資童軍：名稱、圖案、次序跟綱要；位置跟手冊 P.170

2026 年 8 月版綱要冇佩戴位置圖（只係話「詳見手冊」），所以：

- **跟綱要**：段章「活動策劃／社會服務／多元技能／戶外探險」同金帶（P.16、P.21–24）、深資童軍獎章、榮譽童軍獎章（英文 Dragon Scout Award）、新深資童軍急救章圖（P.50）、宗教章、社區參與章、空勤員章（初／中／高）、海上活動徽章（水手長／副舵手／舵手）、第三章世界童軍組織徽章、積極公民。
- **跟手冊 P.170 附圖同 P.129–157 文字**：位置。

| 位置 | 章（由先至後） |
|---|---|
| 右胸袋袋蓋（緊貼） | 金紫荊、總領袖獎章標誌（由右至左），深資童軍先修章喺佢哋左方（內側，P.143） |
| 右胸袋袋蓋上方 3 cm | 宗教章／公教章（內側）、和平使者章或紀念章（外側），最多兩個 |
| 右胸袋中央 | 深資童軍獎章／榮譽童軍獎章（只戴最高） |
| 左胸袋袋蓋 | 服務年星（紅色一至六年，P.129） |
| 左胸袋袋蓋上方 | 飛行章／跳傘章 2 cm，香港章喺上面（只得香港章時 3 cm） |
| 右袖旅章下面 | 深資童軍急救章（P.148）→ 地域章（前）、區章（後），相距 1 cm → 社區參與章、世界童軍組織徽章、積極公民一行最多四個 |
| 左袖第一行 | 航空活動徽章（前）、深資童軍急救章（中）、海上活動徽章（後）→ 香港青年獎勵計劃（銅／銀／金）→ 拯溺布章 |
| 左袖下面兩行兩欄 | 段章，每個下面一條金帶；最底一行金帶貼住袖口縫線 |

- 急救章一個開關、兩隻袖都戴：新欄位 `alsoAnchor`（第二個位置，key 加 `-2`）。
- 右袖改用 slot `sleeveR`（`belowBadge: 'troop'`）：開咗急救章，地域章、區章自動向下移；冇就照 P.95 喺旅章下 2 cm。新層屬性 `spacingCm`（同一行章與章之間，地域章／區章 1 cm）。
- 金帶 `requires` 對應段章；冇段章就唔顯示（原因 `needsStage`）。
- 段章位置：附圖冇寫邊個段章喺邊格，模型按綱要次序由上至下、由前至後（活動策劃、社會服務；多元技能、戶外探險）。
- 手冊附圖嘅（舊）深資童軍世界童軍環境章 2026 年綱要已冇，改為第三章嘅地球部落等徽章，同社區參與章一行最多四個（參照樂行童軍綱要 P.12）。
- 綱要 P.61–62 冇印空勤員章、海上活動徽章圖（只有網址）：用樂行童軍綱要 P.35 高級空勤員章、舵手章圖示意，低級標明「示例」。
- 未示範：以前支部嘅服務年星、樂行童軍先修章（冇文件講戴喺深資童軍制服邊度）（`notAllowed.preEntry`）。
