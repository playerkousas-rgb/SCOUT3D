# 0005 — 童軍支部：海童軍、空童軍做「制服款式」

SCOUT3D v1.0 · © SCOUT SYSTEM

- Status: accepted（2026-11-14）

用戶指示：「繼續童軍支部的海童軍及空童軍」，做齊成個童軍支部先開始深資童軍。

## 背景

手冊 P.32–35 同綱要 P.13–14：海童軍、空童軍嘅徽章欄同童軍一字不差（世界童軍會員章、香港章、地域章、區章、旅章、小隊章），附圖嘅袖章位置亦一樣。唔同嘅只有：

| | 童軍 | 海童軍 | 空童軍 |
|---|---|---|---|
| 帽 | 深綠色軟帽 + 童軍帽章 | 白頂帽 + 「SEA SCOUTS」帽帶 | 灰藍色軟帽 + 童軍帽章 |
| 恤衫 | 杏色 | 白色 | 淺藍色 |
| 短褲／裙褲 | 草青色 | 深藍色 | 深藍色 |
| 長襪 | 深草青色 | 深藍色 | 深藍色 |

皮帶、皮鞋、領巾、巾圈三款一樣。

## 決定

- **唔開新支部，喺童軍入面加 `variants`**：`scout_rules_v1.0.json` 嘅 `variants[]`（land／sea／air）。每款只列出有分別嘅衣物，用同一個 `id` 換走基本衣物（`garmentsFor()`）。徽章同擺位只有一份，所以三款一定一樣（有測試）。
- **配色**：`body.js` 嘅 `SCOUT_VARIANTS`。顏色取自綱要 P.13–14 附圖：深藍 #313166、淺藍 #94afdb、灰藍軟帽約 #1e314d。
- **海童軍白頂帽**：跟手冊 P.100、P.102。帽邊離眉約 2 cm、水平；黑色帽帶喺白邊下面，「SEA SCOUTS」字放喺帽前中央；穿著者左邊中央綁蝴蝶結，蝴蝶結同帽帶尾各長 3 cm。帽帶圖案係 P.102 相片裁出嚟，冇重畫。
- **空童軍軟帽**：同童軍軟帽同一形狀，換顏色；帽章同童軍一樣（手冊 P.102「童軍、空童軍……佩戴」）。
- **小隊章隊色方向**：用戶確認，以人望住小隊章嘅面向，圖案左色近背、右色近胸。右袖貼片嘅圖案右手邊指向 +z（胸前），由 `sleevePose()` 計，有測試鎖定。

## Considered Options

- 開 `sea_rules`／`air_rules` 兩個新檔：徽章資料要抄三份，容易唔一致，否決。
- 用 `picks` 存款式：款式係衣著，唔係徽章圖案，放 `outfit.variant` 比較清楚。

## Consequences

- `SourcesTab` 要知道 `variant` 先顯示啱嘅衣物規則。
- 副標題、截圖說明同檔名用 `scout_sea`／`scout_air`。
- 深資童軍之後可以用同一個方法處理深資海童軍、深資空童軍。
